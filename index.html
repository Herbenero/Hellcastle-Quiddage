Quidditch Darts Rulebook

1. Basic Gameplay: Throw 3 physical darts per turn, then use the keypad to log hits.

2. Segment Aiming: Each scoring button displays the exact dartboard segment number you should aim for.

3. Golden Snitch: Once unlocked at 75% score, the Snitch hides on a randomized segment each round. Catch it on that exact segment to claim 150 points!
